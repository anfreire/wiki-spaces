# skills

## What this space is

The three reference skills that ship with wiki-spaces, installable via `npx skills add anfreire/wiki-spaces`. Each one is self-contained: a `SKILL.md` carrying the shared core block (duplicated verbatim across the three — pinned by the test suite) and a byte-identical copy of `scripts/ws.py`; ws-update also bundles `references/` for its deep procedures. The harness reads the `description:` frontmatter to decide invocation. Obsidian syntax lives in the companion skills (`npx skills add kepano/obsidian-skills`).

## Items

- [ws-search/SKILL.md](ws-search/SKILL.md) — find content in the wiki
- [ws-update/SKILL.md](ws-update/SKILL.md) — capture, place, and sync content
- [ws-tend/SKILL.md](ws-tend/SKILL.md) — status, audit, normalize
